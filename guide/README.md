# Indeks Panduan Pengembangan Lokal & Database

Selamat datang di direktori panduan pengembangan lokal project **porto-astro**. Direktori ini berisi dokumentasi terpisah berdasarkan topik untuk memudahkan Anda mengelola database, environment, dan alur kerja deployment.

Silakan pilih panduan yang Anda butuhkan di bawah ini:

1. 💻 **[Panduan Menjalankan Project & Deployment](file:///f:/Career/Web%20Design/porto-astro/web-porto/guide/wrangler_and_preview.md)**
   Panduan menjalankan aplikasi lokal menggunakan Astro Dev, Cloudflare Wrangler Dev (Lokal), atau Wrangler Dev (Remote Mode), alur kerja deployment manual, serta troubleshoot autentikasi.

2. 🗄️ **[Panduan Cloudflare KV (Key-Value) Namespace](file:///f:/Career/Web%20Design/porto-astro/web-porto/guide/kv_namespaces.md)**
   Daftar perintah (*cheat sheet*) lengkap untuk mengelola Cloudflare KV baik di lokal maupun remote, termasuk sinkronisasi dan manajemen data.

3. 📂 **[Panduan Drizzle ORM & Cloudflare D1](file:///f:/Career/Web%20Design/porto-astro/web-porto/guide/drizzle_orm_d1.md)**
   Instruksi lengkap seputar skema database menggunakan Drizzle, pembuatan migrasi, penerapan migrasi ke database D1 lokal dan remote, serta cara menggunakan Drizzle Studio.

4. 👑 **[Panduan Konfigurasi Admin Database D1](file:///f:/Career/Web%20Design/porto-astro/web-porto/guide/admin_configuration.md)**
   Langkah-langkah cepat untuk menjadikan akun pengguna Anda sebagai `admin` di database D1 lokal maupun remote produksi.
