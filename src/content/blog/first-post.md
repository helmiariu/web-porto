# Membangun Web Cepat dengan Astro

Astro adalah framework web modern yang memungkinkan kita membangun website super cepat. Alih-alih mengirimkan megabyte JavaScript ke klien, Astro me-render semuanya menjadi HTML statis saat *build time*.

## Kenapa Astro?
Astro sangat cocok untuk website *content-heavy* seperti blog dan portfolio. Fitur **Content Collections** memudahkan saya menulis artikel menggunakan Markdown dengan skema validasi yang kuat.
