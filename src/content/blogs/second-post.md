# Membangun Web Cepat dengan Astro

Astro adalah framework web modern yang memungkinkan kita membangun website super cepat. Alih-alih mengirimkan megabyte JavaScript ke klien, Astro me-render semuanya menjadi HTML statis saat _build time_.

## Kenapa Astro?

Astro sangat cocok untuk website _content-heavy_ seperti blog dan portfolio. Fitur **Content Collections** memudahkan saya menulis artikel menggunakan Markdown dengan skema validasi yang kuat.
